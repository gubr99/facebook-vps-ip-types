## 多账号防关联：内存、子网和预热的具体数字

内存按“同时活跃的浏览器配置文件”计算，每个活跃配置预留 150–200MB；IP 层面最重要的规则只有一条：别把多个号压在同一个 /24 子网里，Facebook 会关联同子网的账号。

换算成具体做法：

- 2GB 内存的机器，同时活跃的配置文件别超过 5 个；2 核 2GB 的配置大约能撑 8–12 个配置文件轮换，用任务调度器让它们分时段“醒着”，而不是全部 24 小时在线。
- 总量 30 个号的话，拆成 3–4 台不同子网的机器，最好分布在不同地区——亚太账号配香港节点，美国账号配洛杉矶节点，让 VPS 位置和账号资料一致。
- 新号预热 7–14 天，模拟真人的使用节奏。注册当天就加几十个群或者直接投广告，基本等于宣告这个号作废，IP 再干净也救不回来。

## 常见问题

**一台 Facebook VPS 能挂多少个号？**
技术上取决于内存（每个活跃配置 150–200MB），风险上取决于 IP 策略。2GB 内存建议同时活跃不超过 5 个配置文件；账号总量大就拆多台机器、分散子网，别全塞一台。

**需要独立显卡吗？**
只开网页不需要。跑安卓模拟器才需要真 GPU——没有独显的 VPS 会回退到软件渲染，刷信息流会卡顿掉帧，重一点的 App 基本没法稳定运行。

**新账号要养多久？**
7–14 天。这段时间维持正常人的使用节奏，别加群、别投广告、别频繁改资料，之后再逐步上强度。

**几美元的通用 VPS 能用来操作账号吗？**
跑发布工具可以，操作账号不建议。便宜机房的 IP 常有回收和滥用历史，注册后几小时内就触发验证的情况并不少见。
